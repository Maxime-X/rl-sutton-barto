# rl-sutton-barto
A self directed study project working through Sutton & Barto's Reinforcement Learning: An Introduction, with my own implementations (not copied from reference solutions) of the book's exercises.

## Contents

### Chapter 2 -- Multi-Armed Bandits
- Implemented and compared ε-greedy, UCB, gradient bandit, and optimistic bandits
- Simulated a full non-stationary parameter study (exercise 2.11) comparing 5 methods across a range of parameters
- Vectorized simulations across runs using NumPy for a ~35x speedup
